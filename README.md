# Quantified Me: Sleep, Stress, and Academics

This repository contains a CPSC 222 Quantified Self project analyzing the relationship between academic stress, sleep, movement, and respiratory rate.

## Files

- `quantified_self_sleep_stress_project.ipynb`: main Jupyter Notebook report
- `utils.py`: helper functions used by the notebook
- `apple-health-data.csv`: Apple Health export data
- `daily-stress.csv`: manually collected stress log

## Project Question

Can sleep, exercise, step count, respiratory rate, exam days, assignment due dates, and mood help predict whether a day is high stress or low stress?

## How to Run

1. Put `quantified_self_sleep_stress_project.ipynb`, `utils.py`, `apple-health-data.csv`, and `daily-stress.csv` in the same folder.
2. Open the notebook in Jupyter Lab or VS Code.
3. Run the notebook cells from top to bottom.
